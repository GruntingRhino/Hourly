# GoodHours pilot legal/privacy package

**Status:** candidate draft / not approved for publication, signing, or production use. Prepared 2026-09-05 from a read-only GoodHours source inspection and current primary-source retrieval. No attorney or other qualified professional review was obtained; no school/district approval, executed DPA, legal entity verification, signatory authority, provider contract, deployment proof, or production-retention proof is represented.

This package is substantive and fillable. It is not a legal opinion, certification, compliance attestation, authorization, consent, signature, or school decision. It does not claim FERPA/COPPA compliance, COPPA inapplicability, verified age, universal parent consent, universal incident deadlines, or enabled providers.

## Evidence classes

- **Verified product fact:** source evidence in `PRODUCT_EVIDENCE.md` with file/line references.
- **Proposed commitment:** a draft control the operator/school must approve, implement, and verify.
- **NEEDS OWNER INPUT:** a fact, decision, contract term, contact, provider, jurisdiction, retention period, or signature that cannot be inferred.
- **Qualified legal/school question:** an applicability, role, authority, or enforceability issue not decided by this package.
